---

## 2. Core Engine Modules (`src/`)

All core logic is implemented in TypeScript under `src/`:

| Module Path | Primary Responsibility | Key Exports |
| :--- | :--- | :--- |
| `src/index.ts` | Public SDK entrypoint for external consumers and agents | `pack`, utility helpers, types |
| `src/cli.ts` | Commander-based CLI executable (`cx`, `cpack`, `context-pack`) | CLI parser, argument sanitization, exit code dispatcher |
| `src/packer.ts` | Pipeline orchestrator and greedy knapsack selection | `pack()` |
| `src/slicer.ts` | File resolution and Task-Aware Window Slicing | `sliceRelevantLines()`, `sliceLines()`, `resolveFiles()` |
| `src/ranker.ts` | BM25 term weighting and keyword scoring | `rankFiles()`, `extractKeywords()`, `scoreFileRelevance()` |
| `src/tokenizer.ts` | `js-tiktoken` wrapper and singleton encoder cache | `countTokens()`, `isValidEncoding()` |
| `src/formatter.ts` | High-contrast picocolors terminal output formatter | `formatResult()`, `stripAnsi()` |
| `src/dictionary.ts`| English & Vietnamese synonym mapping and accent stripping | `VI_EN_SYNONYMS`, `removeVietnameseAccents()` |
| `src/errors.ts` | Typed domain error hierarchy and POSIX exit code mappings | `ContextPackError`, `ERROR_EXIT_CODES` |
| `src/types.ts` | Type definitions for options, slices, and envelopes | `PackOptions`, `ContextPackEnvelope`, etc. |

*(source: `src/`)*

## 4. Test Suite Layout (`test/`)

Vitest test suites enforce 100% pass rates across all modules:

- `test/cli.test.ts` — CLI invocation, argument validation, POSIX exit codes, comma-separated files.
- `test/packer.test.ts` — Knapsack token packing, budget overflow truncation, deterministic sorting.
- `test/slicer.test.ts` — Task-Aware Window Slicing, hotspot line alignment, asymmetric context lead.
- `test/ranker.test.ts` — English & Vietnamese keyword extraction, BM25 relevance scoring.
- `test/tokenizer.test.ts` — Token counting precision across encodings, empty string bounds.
- `test/formatter.test.ts` — Terminal summary text formatting and ANSI code stripping.

*(source: `test/`)*
